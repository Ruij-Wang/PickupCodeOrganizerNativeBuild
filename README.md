# 取件码整理

Android 原生 MVP，用通知监听整理短信、购物 App、微信等通知里的快递取件信息。默认不申请短信读取权限，不上传通知内容。

## 已实现

- `NotificationListenerService` 采集通知标题、正文、来源应用、发送时间。
- Room 存储原始通知 `RawMessage` 和结构化取件条目 `PickupItem`。
- 本地规则抽取应用归属、驿站地点、取件码、截止日期提示。
- 同来源同取件码去重，支持未取、已取、忽略状态。
- WorkManager 对未取件条目生成本地提醒。
- Compose UI：首页概览、取件列表、详情编辑、采集诊断、监听白名单、规则测试。
- 单元测试样本覆盖京东、菜鸟、淘宝、拼多多、短信、微信和异常文本。

## 采集边界

- 真实通知：已接入。开启 Android 系统的“通知访问”后，App 会接收白名单应用的新通知，并保存到“采集”页。
- 短信：当前读取的是短信 App 弹出的通知内容，不直接读取短信数据库，也没有申请 `RECEIVE_SMS`。
- 本地模型：当前版本还没有打包小模型，实际抽取方式是本地规则引擎；代码里预留了 `LocalAiExtractor` 接口，后续可接入 ONNX/TFLite/llama.cpp 类本地模型。

## 运行

1. 用 Android Studio 打开本目录。
2. 等待 Gradle 同步，安装到 Android 设备。
3. 在系统设置中开启“取件码通知整理”的通知访问权限。
4. Android 13 及以上需要在 App 内授权提醒通知权限。
5. 进入 App 的“采集”页，查看最近真实捕获到的原始通知。
