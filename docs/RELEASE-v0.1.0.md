# 取件码整理助手 v0.1.0 发布说明

## 面向体验者

这个版本用于展示“通知采集—本地抽取—统一取件清单—状态与提醒”的核心产品闭环。

APK 与 GGUF 应作为同一个 GitHub Release 的两个独立下载资产发布。源码仓库保留应用代码和文档，二进制资产不进入 Git 历史。

## 安装顺序

1. 下载并安装 APK。
2. 开启系统通知访问权限。
3. 先用规则模式体验通知采集与取件码整理。
4. 如需体验端侧模型，再下载 GGUF 并从设置页导入。
